这是什么

一台跑在手机里的完整虚拟机，不是 chroot、不是 proot。

Qodroid 基于 ExTV/Podroid 修改而来（GPL v2，包名 com.pxkf.qodroid）。它在 arm64 手机上运行带独立内核的 Alpine Linux，Podman / Docker / LXC 的行为与服务器一致；也可以加载自己的磁盘镜像， 启动 x86 Windows 虚拟机。内置终端、图形桌面查看器与容器管理，开箱即用。

核心特性

为日常使用与折腾都留了空间

▣

真实的 Linux VM

Alpine + 自编译内核，可安装 Podman / Docker / LXC，与服务器行为一致。

▤

Windows 支持

加载自有磁盘镜像，q35 + OVMF/UEFI 固件，内置 VNC 查看器看桌面。

⚡

双引擎

普通设备用 QEMU（TCG）；支持 pKVM 的设备可选 AVF 硬件加速。

❯

内置终端

完整 xterm-256color，多主题字体，实时改窗口大小，快捷键齐全。

▦

X11 / VNC 桌面

触摸、键盘、鼠标与音频；触摸板模式默认开启，窗口可拖动。

▤

容器备份

备份 / 恢复 podman 与 docker 的容器和镜像，自动检测可用引擎。

⇄

共享文件夹

SSH 与端口转发

从电脑 ssh 进虚拟机，或把 guest 端口暴露到局域网。

快速开始

装好就能用，全部操作无需 root

  1. 下载并安装 Qodroid-2.0.0.apk
  2. 打开应用，点 启动虚拟机
  3. 等待状态变为 Ready
  4. 打开终端，开始使用容器
Linux 默认账号 root / podroid，SSH 端口 9922。 改密码会中断应用内的自动登录与文件管理，请谨慎。

Windows 虚拟机

加载镜像即可启动，桌面走内置 VNC

  • 选择磁盘镜像，切换 UEFI / BIOS 固件
  • 默认启用 USB 绝对定位指针，鼠标不再漂移
  • VNC 默认仅本机可看，可按需暴露到局域网
  • 底部快捷键含 DEL / ENTER / WIN / F1–F12
  • 若无法上网：在 Windows 网卡把 DNS 设为 8.8.8.8 与 223.5.5.5
ping 不通是正常的：虚拟机 NAT 不转发 ICMP，判断联网请直接打开网页。
